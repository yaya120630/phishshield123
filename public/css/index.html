🔐 How PHISHSHIELD Works

1. User visits a website
The user opens a website using their browser.
2. Browser Extension detects the URL
The PHISHSHIELD browser extension captures the website URL.
3. URL Analysis
The system checks the URL based on predefined rules, such as:
  • Suspicious keywords
  • Unusual domain names
  • Very long URLs
  • IP addresses used instead of domains
  • HTTPS/security information
  • Suspicious URL structures
4. Risk Detection
The system classifies the URL into different categories:
🟢 SAFE — No significant suspicious characteristics detected.
🟡 SUSPICIOUS — Some characteristics may indicate a phishing attempt.
🔴 PHISHING / DANGEROUS — The URL matches multiple phishing indicators.
5. User Warning
If the website is considered dangerous, PHISHSHIELD displays a warning to the user:
⚠️ Warning: This website may be a phishing site.
The user can then choose whether to leave the website.
6. AI Explanation
The AI component is used to generate a simple explanation of the detection result.
